# Лапки — студия идей для рилсов

Рабочий интерфейс прототипа для блога о карликовом пуделе. React 19 + Vite, Node.js 22.12+ (проверено на Node.js 24).

## Открыть без установки

[Скачать готовое приложение с GitHub](https://github.com/webtkach/test/raw/refs/heads/main/downloads/lapki.zip). Распакуйте архив и откройте `lapki.html` в Chrome, Edge или Firefox. Это ссылка на архив в репозитории; отдельный сайт GitHub Pages пока не опубликован.

Готовый архив `artifacts/lapki.zip` содержит автономное приложение. Извлеките архив и откройте `lapki.html` в обычном браузере. Шрифты, картинки и код включены в файл; сервер и Node.js не нужны. Встроенный просмотр файлов в чате не является хостингом приложения.

Чтобы пересобрать этот архив из исходников: `npm run build:standalone`. Внешние ссылки и встраиваемый Instagram требуют интернета. Данные автономной версии сохраняются отдельно от версии на сервере; перемещение HTML-файла может изменить область локального хранилища браузера.

Проверка автономного файла без внешних ресурсов: `APP_HTML=artifacts/lapki.html APP_OFFLINE=1 npm run test:e2e`. Тест подаёт содержимое файла прямо в браузер через перехват запроса; все остальные запросы запрещены. Прямой переход на `file://` в управляемом Chromium этой облачной среды запрещён политикой браузера и здесь не проверен.

## Запуск для разработки

```sh
cd /workspace/test
npm ci
npm run dev -- --port 5173
```

## Что работает

- Лента с редакционным рейтингом, поиском, тематическими и географическими фильтрами.
- Отдельная страница идеи: сценарий по секундам, подпись, лид-магнит, заметки к съёмке.
- Редактор с сохранением, избранное, настройки блога, список авторов для наблюдения.
- Добавление реальной ссылки на рилс, кнопка Instagram и загрузка официального embed по запросу. Сам Instagram может ограничивать встраивание.
- Адаптивная мобильная версия, модальные окна с поддержкой клавиатуры.

Данные сохраняются в `localStorage` текущего браузера, без аккаунтов, синхронизации или серверной базы. Очистка данных сайта удаляет изменения.

## Границы прототипа

Шесть стартовых карточек — **демонстрационные концепции**, основанные на описании пользователя. Они не являются найденными вирусными публикациями. Оценки — редакционные приоритеты, не просмотры и не прогноз охвата. Сценарии подготовлены заранее, модель ИИ пока не подключена. Импорт ссылки создаёт редактируемую заготовку, не транскрибирует видео. Лид-магниты — идеи материалов: сами материалы и отправка в Direct не реализованы.

Список зарубежных авторов содержит **кандидатов для исследования**, а не подтверждённых конкурентов или трендсеттеров. В текущей среде запросы к Google и Instagram возвращают `Tunnel connection failed: 403 Forbidden`. Текущая активность, метрики и раннее использование трендов не проверены. План анализа: [docs/research.md](docs/research.md).

Для следующего этапа нужны разрешённый источник Instagram-данных, хранилище наблюдений и серверный вызов модели ИИ. Ключи следует хранить на сервере, не в `VITE_*` и не в браузерном коде. Будущий поиск должен сохранять URL, автора, дату публикации, время наблюдения и подтверждённые метрики; при отсутствии метрик показывать отсутствие данных. Не выводить редакционную оценку как измеренный рост.

## Проверки

```sh
npm test
npm run build
# С работающим dev-сервером; системный Chromium или CHROMIUM_PATH:
npm run test:e2e
```

Browser-тесты выполняются через Playwright, снимки записываются в игнорируемый `test-results/`. Визуальные иллюстрации локальные и не требуют Unsplash или Google Fonts.
